# LHD Ballast Trainer

Wasp-class ballast / deballast simulator for training. Unofficial training aid.

Open `index.html` in a browser, or use the GitHub Pages site for this repository.

The two-screen instructor/trainee link works only on claude.ai. On this site, use Solo mode.
