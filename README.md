# LHD Ballast Trainer

Wasp-class ballast / deballast simulator for training. Unofficial training aid.

Open `index.html` in a browser, or use the GitHub Pages site for this repository.

Two screens: open the page on both, pick Trainee on one and Instructor on the other, and use the same session code. This links two windows on one computer, and two computers when the network allows a direct connection. The Instructor screen needs the instructor password.

Spoken radio reports need Chrome or Edge. Edge has the most natural voices.
